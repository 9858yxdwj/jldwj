## 结论先行

《小小屠龙》（冰雪复古版本）官方主打的是**高爆打宝 + 装备不绑定 + 自由交易**，并强调装备由野外产出、不售卖成品毕业装。由此可以推出一条相对稳妥的散人路线：

> **先保证「打到的东西能换钱」，再考虑「怎么打得更快」。**

具体说：前期别急着追高阶装备，优先把挂机效率、回收换元宝的循环跑通，同时**提前囤转生材料**——多数卡进度的情况，都卡在材料而不是等级。

## 一、先把经济循环跑通

| 环节 | 做什么 | 为什么重要 |
| --- | --- | --- |
| 挂机刷怪 | 用离线/后台挂机稳定产出 | 官方强调离线也能获得收益，适合碎片时间 |
| 拾取过滤 | 挂机前先设好要捡什么、自动忽略什么 | 背包被低级装塞满时，关键掉落可能捡不到 |
| 装备回收 | 低级装备一键回收换元宝 | 元宝是开启狂暴、进高阶地图、合成特装的核心通货 |
| 自由交易 | 非绑定装备经游戏内摆摊 / 寄售流转 | 官方强调装备保值，散人靠打宝也能积累资源 |

**建议**：给自己定一个简单规则——每天先把可回收的低级装备清掉换成元宝，再决定要不要继续刷图。别让背包塞满过渡装，那是最常见的资源浪费。

## 二、转生：优先囤材料，别一味堆等级

官方介绍中，转生是重要成长线：需要**同时满足等级条件 + 转生材料**，材料由精英怪与 BOSS 掉落；转生后等级会回落但属性永久保留，并解锁新地图与高阶装备。

由此得到两条实操原则：

1. **材料优先于等级**：能打精英/BOSS 时优先打，提前囤料，避免到门槛时卡住；
2. **转生节点决定地图权限**：高阶地图与稀有产出集中在后续大陆，所以推进转生比单纯刷等级更能打开产出上限。

> 避坑：别在临近转生时把元宝全花在过渡装强化上。转生后装备会换代，这部分投入回报很低。

## 三、装备养成：先凑四件套，再追词条

官方公开的装备体系大致分为基础过渡装、转生装备、特装（斗笠/盾牌/玉佩/勋章等）与稀有特戒。按性价比排序通常是：

1. **特装四件套**：优先凑齐，套装加成可观，单件也有独立属性；
2. **转生装备**：中后期主力，主要由高阶 BOSS 产出；
3. **词条/强化**：词条优先攻击、吸血、暴击方向；强化有风险，注意保护类道具的使用时机；
4. **稀有特戒**：随缘获取，不建议刻意硬肝。

具体等级门槛与合成规则请以游戏内为准，本文不给出未经实测的数值结论。

## 四、职业设定：不同渠道说法不一致，别先下结论

关于职业，公开渠道文案存在两种说法：一种写「单职业」（一个角色融合多种定位，靠词条与加点分流派），另一种写「战法道三职业 + 可切换」。**本站未做实测，不做断言**，请以游戏内职业面板为准。

如果当前版本确实支持按场景切换，那么常见的思路是：

| 场景 | 更合适的方向 |
| --- | --- |
| 清怪刷图 | 群伤 / 范围输出，效率高 |
| 打 BOSS | 续航与吸血优先，能长时间站住 |
| PK / 攻城 | 扛伤与爆发，注意减伤 |

但真正决定散人效率的，通常不是开局选了哪个职业，而是转生节点、装备词条与挂机设置。切换条件与技能是否保留，请以游戏内说明及官方公告为准。挂机设置部分可继续看《小小屠龙 挂机前检查清单：拾取过滤、自动回收与交易安全》。

## 五、行会与攻沙

沙城争夺、行会攻沙是官方主打的团战内容，战士扛城门、法师铺火墙、道士加状态是常见的配合思路。散人玩家加入活跃行会的收益通常高于独自刷图，但涉及奖励、排名规则等，**一律以官方公告为准**，不要轻信社群转述。

## 常见坑

- **认错下载渠道**：官方反复提示存在仿冒与私服版本，请认准官方渠道，避免账号与充值风险。
- **过早堆过渡装**：转生后装备换代，前期过度投入回报低。
- **只刷等级不囤材料**：到转生门槛时才发现材料不够，白等几天。
- **忽略回收与拾取过滤**：低级装备堆在背包里不处理，等于把元宝锁死，还会挤掉关键掉落。
- **经验类道具一次吃完**：公开渠道普遍建议留一部分到转生等级回落之后再使用，是否适用请以当前版本规则为准。
- **私下交易 / 外挂脚本**：优先使用游戏内置的交易渠道；外部「福利码」、脚本与私下交易都有账号和资产风险。
- **轻信「稳赚回本」**：本站不提供任何收益承诺，物价与活动规则以游戏内及官方公告为准。
